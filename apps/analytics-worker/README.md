# Analytics Worker

Executes analytical queries against versioned datasets.

## Responsibilities

- Query execution
- DuckDB integration
- Parquet scanning
- Query cancellation
- Resource isolation
- Query result caching
- Execution metrics

## Technology

- Node.js
- TypeScript
- DuckDB
- Apache Parquet
- BullMQ
- Redis
