# API Application

The primary backend API for the Excel Dashboard SaaS platform.

## Technology

- NestJS
- TypeScript
- PostgreSQL
- Prisma
- Firebase Admin SDK
- Redis
- BullMQ

## Responsibilities

- Identity and authentication
- Workspace management
- Tenant authorization
- File upload orchestration
- Dataset management
- Analytical query orchestration
- Visualization management
- Dashboard management
- Sharing and publishing

The application workspace is registered.
