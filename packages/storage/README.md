# @excel-dashboard/storage

Shared server-side S3-compatible object storage infrastructure for Excel Dashboard.

## Responsibilities

- S3 client configuration and connection management.
- Workspace-scoped object key generation.
- Object upload, download and deletion.
- Multipart streaming uploads.
- Presigned upload and download URLs.
- Object metadata retrieval.
- Storage error normalization.
- Dependency health checks.
- Resource lifecycle management.

## Supported environments

Local development and integration tests use SeaweedFS. Staging and production use AWS S3.

## Consumers

- @excel-dashboard/api
- @excel-dashboard/ingestion-worker
- @excel-dashboard/analytics-worker

This package must not be imported into browser applications.

## Lifecycle

Create one storage runtime per application process using createStorageRuntime(loadStorageConfig()).

Reuse the runtime's storage service throughout the application. Close the runtime only after active storage operations have completed.

## Security

All application objects must use workspace-scoped keys generated by ObjectKeys.

Workspace prefixes are not an authorization mechanism. Consumers must verify workspace membership and resource ownership before performing storage operations.

Never expose storage credentials or log complete presigned URLs.

## Testing

Run unit tests using npm run storage:test.

Run integration tests using npm run storage:test:integration after configuring SEAWEEDFS_VERSION and starting Docker.

Integration tests provision an isolated SeaweedFS container.
