# Product Documentation

Excel Dashboard is a standalone multi-tenant SaaS
platform for spreadsheet-based business intelligence.

## Core Product Workflow

1. Create a workspace.
2. Upload a spreadsheet.
3. Configure and import datasets.
4. Explore data.
5. Create analytical queries.
6. Build visualizations.
7. Compose interactive dashboards.
8. Publish and share dashboards.
